# Kurdora

A planned multi-vendor marketplace for Kurdish communities across Europe.

> **Status: PHASE 0 — planning only.** No application code exists yet.
> "Kurdora" is a working brand name and is isolated behind a brand configuration
> module so it can be changed without touching application code.

## Start here

**→ [`docs/README.md`](./docs/README.md)** — the full planning documentation set:
technology stack, system architecture, database design, Stripe Connect payment
architecture, roles and permissions, transaction flows, commission engine, security
model, internationalisation/RTL, roadmap, and risks.

Two documents to read first:

- **[`docs/04-payments-architecture.md`](./docs/04-payments-architecture.md)** —
  contains a critical finding about commission rates versus payment processing costs.
- **[`docs/00-scope-and-open-questions.md`](./docs/00-scope-and-open-questions.md)** —
  the decisions needed before implementation can begin.
